# lorax: Speak for the Trees

Provides a unified interface for extracting information from tree- and
rule-based models. Functions include extracting logical rules that
define terminal nodes, identifying predictors that were actually used in
splits, retrieving variable importance scores, and converting trees to
the 'partykit' format for visualization. Supports models from packages
including 'rpart', 'ranger', 'randomForest', 'xgboost', 'lightgbm',
'C50', 'Cubist', 'bart', and 'grf'.
